# Руководство пользователя Amber Desk

[English version](USER_GUIDE.md)

## 1. Что хранит Amber Desk

Amber Desk - локальное веб-приложение. Браузер обращается к Go-бэкенду на вашем компьютере.

При настроенном Obsidian бэкенд хранит дела как файлы в существующем локальном vault. Без подключенного провайдера хранения поддерживаемые рабочие области используют память процесса. Данные в памяти пропадают после остановки Amber Desk.

Amber Desk находится на ранней стадии разработки и не является промышленной системой управления доказательствами. Храните независимые резервные копии и отдельно проверяйте важные доказательства.

## 2. Запуск Amber Desk

Требования:

- Go 1.22 или новее
- Современный настольный браузер
- Опционально: существующий vault Obsidian
- Опционально: Python и комплектный скрипт установки Sherlock

Запуск без Obsidian:

```powershell
git clone https://github.com/doctorFrankinshtane/amber_desk.git
cd amber_desk
go run .
```

Откройте <http://localhost:8080>.

Чтобы использовать другой порт в PowerShell:

```powershell
$env:ADDR = ":8081"
go run .
```

Переменные окружения действуют в текущей оболочке. После их изменения перезапустите Amber Desk.

## 3. Подключение Obsidian

Amber Desk работает с vault через локальную файловую систему. Плагин Obsidian не требуется.

1. Остановите Amber Desk.
2. Задайте в `OBSIDIAN_VAULT` абсолютный путь к существующему vault.
3. При необходимости задайте относительный каталог досье.
4. Запустите Amber Desk из той же оболочки.

```powershell
$env:OBSIDIAN_VAULT = "C:\Users\you\Documents\My Vault"
$env:OBSIDIAN_DOSSIER_DIR = "Amber Desk\Dossiers"
go run .
```

Значение `OBSIDIAN_DOSSIER_DIR` по умолчанию - `Amber Desk/Dossiers`. Путь должен быть относительным к vault. Кнопка **VAULT** в шапке показывает состояние коннектора:

- `ПОДКЛЮЧЕНО`: каталог vault доступен.
- `НЕ НАСТРОЕНО`: при запуске процесса не был задан `OBSIDIAN_VAULT`.
- `VAULT НЕДОСТУПЕН`: настроенный путь недоступен.

Нажмите **VAULT**, чтобы редактировать Markdown текущего досье. Кнопка **ПЕРЕЧИТАТЬ** загружает изменения из Obsidian, а **СОХРАНИТЬ В VAULT** записывает содержимое редактора. Если после загрузки файл изменился, сохранение отклоняется как конфликт внешнего изменения. Перед продолжением перечитайте файл.

### Структура vault по умолчанию

```text
Amber Desk/
  Dossiers/
    <case-id>.md
  Cases/<case-id>/
    Checklist.md
    Timeline/<event-id>.md
    Map/Markers/<marker-id>.md
    Map/Routes/<route-id>.md
    Relations/Nodes/<node-id>.md
    Relations/Edges/<edge-id>.md
    Relations/Attachments/<node-id>/<attachment-id>/
      metadata.json
      content.bin
    .trash/
  .state/
    cases-index.json
    active-case-id.json
    cases/<case-id>.json
  .trash/<case-id>-<timestamp>/
```

Markdown-заметки содержат YAML frontmatter, который использует Amber Desk. Не удаляйте и не переименовывайте структурированные поля без понимания формата. Байты вложения хранятся в `content.bin`, исходное имя и SHA-256 - в `metadata.json`.

## 4. Создание первого досье

1. Нажмите **СОЗДАТЬ ДОСЬЕ** в левой панели или нажмите блок дела в шапке и выберите **СОЗДАТЬ НОВОЕ**.
2. На шаге **ДЕЛО** введите обязательное название. Владелец, цель и теги необязательны.
3. На шаге **СУБЪЕКТ** введите обязательный код. При необходимости добавьте имя, риск, уверенность, местоположение, время последнего наблюдения и псевдонимы.
4. На шаге **СВЯЗИ** добавьте известные идентификаторы и исходные связанные объекты.
5. Нажмите **СОЗДАТЬ И ОТКРЫТЬ**.

При подключенном Obsidian создание записывает в vault снимок дела, досье и начальные записи связей. Файл чеклиста создается при его первой загрузке. Проверяйте подписи бэкенда в интерфейсе: `OBSIDIAN` означает постоянное хранение в vault, `MEMORY` - только в памяти текущего процесса.

## 5. Переключение и удаление досье

Нажмите блок дела в шапке, чтобы открыть **ИНДЕКС ДОСЬЕ**. Найдите дело по названию, ID или субъекту и выберите его. Несохраненные изменения в Markdown-редакторе VAULT блокируют переключение, пока вы не сохраните или не отмените их.

Удаление активного досье:

1. Нажмите **УДАЛИТЬ** рядом с заголовком **ДОСЬЕ ОБЪЕКТА**.
2. Введите точный ID дела из шапки.
3. Нажмите **В КОРЗИНУ**.

Для удаления всего дела нужен подключенный провайдер хранения дел; встроенный провайдер - Obsidian. Досье, каталог дела и сохраненный снимок перемещаются в `Amber Desk/.trash/<case-id>-<timestamp>/`. Активным становится следующее доступное досье. Кнопки восстановления в Amber Desk нет: восстанавливайте файлы вручную из резервной копии или локальной корзины vault при остановленном приложении.

## 6. Хронология и улики

Откройте **ХРОНОЛОГИЯ**.

1. Нажмите `+` на панели хронологии.
2. Укажите заголовок, тип, время наблюдения, сводку, источник и уверенность.
3. Нажмите **ДОБАВИТЬ**.
4. Выберите событие, чтобы открыть **ИНСПЕКТОР УЛИК**.
5. Добавьте заметки аналитика или переключите статус между `НА ПРОВЕРКЕ` и `ПРОВЕРЕНО`.

Поиск и фильтры `ВСЕ`, `ID`, `NET`, `MEDIA`, `SOC`, `FIN` и `TOOL` ограничивают список видимых записей. Удаление события требует подтверждения. При подключенном Obsidian его Markdown-заметка перемещается в `Cases/<case-id>/.trash/Timeline/`.

Markdown-текст предназначен для чтения; структурированные поля хронологии загружаются из YAML frontmatter. Чтобы перечитать файлы хронологии, измененные напрямую в Obsidian, обновите страницу браузера.

## 7. Чеклист расследования

Чеклист находится под данными субъекта в левой панели.

- Установите флажок, чтобы отметить шаг выполненным.
- Нажмите `...`, чтобы изменить название, заметку и статус или закрепить следующий шаг.
- Нажмите `+` в заголовке чеклиста, чтобы добавить свой шаг в выбранную фазу.
- Удалять можно только пользовательские шаги.
- Кнопка `>` у шага открывает связанную рабочую область Amber Desk. Внешний поиск она не запускает.

В прогресс входят выполненные и пропущенные шаги. При подключенном Obsidian полное состояние хранится в `Checklist.md`, иначе - в памяти процесса.

## 8. Карта расследования

Откройте **КАРТА МИРА**.

Добавление локации:

1. Выберите **ДОБАВИТЬ МЕТКУ**.
2. Нажмите на карту.
3. Укажите название, при необходимости время наблюдения и описание.
4. Нажмите **СОХРАНИТЬ**.

Перетащите метку, чтобы изменить координаты. Для добавления перемещения выберите **СОЕДИНИТЬ**, затем две разные метки. Выберите метку или маршрут, чтобы просмотреть или удалить его. При удалении метки также удаляются связанные с ней маршруты.

Комплектная обзорная карта, названия городов, регионы, городские зоны, крупные дороги, реки и озера загружаются из локальных файлов. Карта не обращается во время работы к публичному серверу тайлов.

### Локальные подробные тайлы

Для зданий, адресов, местных улиц, кафе, ресторанов и других POI подключите растровый пакет XYZ:

```text
D:\Maps\amber-xyz\
  0\0\0.png
  1\0\0.png
  1\0\1.png
```

```powershell
$env:MAP_TILE_DIR = "D:\Maps\amber-xyz"
$env:MAP_TILE_EXT = "png"
$env:MAP_TILE_MIN_ZOOM = "0"
$env:MAP_TILE_MAX_ZOOM = "18"
go run .
```

Поддерживаются расширения `png`, `jpg`, `jpeg` и `webp`. Названия и POI должны быть заранее отрисованы создателем пакета. Браузер запрашивает видимые тайлы только у локального бэкенда Amber Desk.

## 9. Доска связей, файлы и фотографии

Откройте **СВЯЗИ**.

- **+ КАРТОЧКА** создает карточку субъекта, организации, аккаунта, локации, инфраструктуры, улики или факта.
- **НИТЬ** соединяет две карточки. Нить хранит название, уверенность, тип, ID событий-источников и заметку аналитика.
- Перетаскивайте карточки для изменения схемы. **АВТО-СЕТКА** пересчитывает позиции.
- Выберите карточку или нить для редактирования в правом инспекторе.
- Основную карточку субъекта удалить нельзя.

Для сохраненной карточки используйте **+ ПРИКРЕПИТЬ ФАЙЛЫ** или **+ ДОБАВИТЬ ФОТО**. В одной карточке может быть до 20 файлов размером не более 10 МиБ каждый. Значок стопки документов на карточке показывает наличие вложений. Первое поддерживаемое изображение JPEG, PNG, WebP или GIF становится обложкой; в списке вложений можно назначить другое изображение.

Кнопка `+` на портрете досье загружает фотографию основного субъекта. Это обложка основной карточки связей, поэтому изменение в любом из этих мест обновляет одно и то же вложение.

Файлы передаются только локальному бэкенду Amber Desk. При подключенном Obsidian они хранятся в `Relations/Attachments` активного дела. Удаленное вложение или вложения удаленной карточки перемещаются в каталог `.trash` этого дела.

## 10. Проверка имен через Sherlock

Sherlock необязателен. Один раз установите зафиксированное локальное окружение:

```powershell
.\tools\sherlock\setup.ps1
```

На Linux или macOS:

```bash
./tools/sherlock/setup.sh
```

Amber Desk автоматически находит `.tools/sherlock`. Для другого совместимого окружения задайте в `SHERLOCK_PYTHON` абсолютный путь к исполняемому файлу Python и перезапустите Amber Desk.

Запуск проверки:

1. Откройте **СВЯЗИ** и выберите исходную карточку.
2. В инспекторе карточки нажмите **СКАН** в разделе **SHERLOCK**.
3. Введите имя пользователя и нажмите **НАЧАТЬ СКАН**.
4. Прочитайте предупреждение о внешних запросах и подтвердите запуск.
5. Выберите фильтр `НАЙДЕНО`, `ПРОБЛЕМЫ` или `ВСЕ`, при необходимости отфильтруйте сервисы по названию.
6. Отметьте только те найденные профили, которые нужно сохранить.
7. Нажмите **ДОБАВИТЬ ВЫБРАННОЕ**.

Также можно ввести `SHERLOCK <username>` в нижней командной строке, но исходная карточка все равно должна быть выбрана.

**Предупреждение о сети:** процесс Sherlock отправляет имя пользователя множеству поддерживаемых сторонних сайтов. Эти сайты видят запросы из вашей сети и могут записать имя, IP-адрес, время и метаданные запроса. Amber Desk не отправляет целевым сайтам заметки и вложения досье. Результаты - кандидаты, а не доказательство личности; импорт выполняется вручную.

Импорт создает карточки аккаунтов с низкой уверенностью и нити `FOUND ON`, добавляет одно событие хронологии со статусом ожидания и прикрепляет JSON-отчет к исходной карточке. По умолчанию запуск инструментов разрешен только через localhost. Ограничение снимается только явным `ALLOW_REMOTE_TOOL_RUNS=1`.

## 11. Каталог OSINT-источников

Откройте **OSINT ИНСТРУМЕНТЫ**. Категории, поиск, фильтры цены и статуса, а также описания берутся из каталога, встроенного в Amber Desk. Просмотр и фильтрация выполняются локально.

- **В ХРОНОЛОГИЮ** записывает выбранный элемент каталога в активную хронологию. Источник при этом не открывается.
- **ОТКРЫТЬ ИСТОЧНИК** открывает сторонний URL в новой вкладке браузера с подавлением HTTP Referer.

**Предупреждение о сети:** после нажатия **ОТКРЫТЬ ИСТОЧНИК** целевой сайт и загружаемые им ресурсы находятся вне Amber Desk. Сайт может получить ваш IP-адрес, данные браузера, введенные запросы, загруженные файлы и собственные cookie. Перед передачей чувствительных данных изучите заметку OPSEC в каталоге и правила сайта. Метка `LOCAL` означает возможность локальной установки инструмента, но не гарантирует, что кнопка **ОТКРЫТЬ ИСТОЧНИК** работает офлайн.

## 12. Язык и компоновка

Выберите `EN` или `RU` в шапке. Выбор сохраняется в `localStorage` браузера на этом компьютере.

На компьютере используйте стрелки рядом с заголовком **ХРОНОЛОГИЯ РАССЛЕДОВАНИЯ**, чтобы независимо скрывать и возвращать левую панель досье и правый инспектор улик. Эти настройки также хранятся в `localStorage`. На узком экране вместо них используйте вкладки `ДОСЬЕ`, `ХРОНОЛОГИЯ` и `УЛИКА`.

## 13. Границы приватности

Полностью локальны при обычном использовании:

- Обмен браузера с бэкендом через `localhost`
- Чтение и запись vault Obsidian
- Хронология, чеклист, карта, доска связей, вложения и фотографии
- Просмотр встроенной обзорной карты и каталога OSINT
- Локально настроенные XYZ-тайлы

Создают или могут создать обращения к сторонним сетевым ресурсам:

- Подтвержденный запуск Sherlock
- Кнопка **ОТКРЫТЬ ИСТОЧНИК** в каталоге OSINT
- Любой сайт или инструмент, открытый отдельно от Amber Desk
- Установка зависимостей через Go, Python, Git или менеджеры пакетов

Amber Desk не анонимизирует внешний трафик. Используйте сетевую конфигурацию, соответствующую расследованию и законодательству. Не публикуйте HTTP-порт в недоверенной сети: в приложении нет аутентификации пользователей.

## 14. Резервное копирование и восстановление

Для постоянного хранения подключите Obsidian и сохраняйте резервную копию всего vault, а не только `Dossiers/`. Каталоги `Cases/` и `.state/` нужны для хронологии, карт, связей, вложений, чеклиста, индекса дел и указателя активного дела.

Рекомендуемый порядок:

1. Остановите Amber Desk, чтобы копирование не совпало с записью.
2. Скопируйте весь vault или создайте его снимок.
3. Храните хотя бы одну копию вне рабочего диска.
4. Проверьте восстановление в отдельный путь vault.

Локальные каталоги `.trash` помогают восстановлению, но не заменяют резервную копию. Amber Desk не выполняет автоматическое резервное копирование, управление сроками хранения, шифрование или восстановление.

## 15. Типовые неисправности

### Страница не открывается

- Посмотрите фактический адрес в терминале.
- Адрес по умолчанию: <http://localhost:8080>.
- Если порт занят, задайте другой `ADDR`, перезапустите приложение и откройте новый порт.
- Не закрывайте процесс в терминале.

### VAULT показывает НЕ НАСТРОЕНО

- Задайте `OBSIDIAN_VAULT` в той же оболочке, из которой выполняется `go run .`.
- Используйте абсолютный путь к существующему каталогу vault.
- После изменения переменной перезапустите Amber Desk.

### VAULT показывает НЕДОСТУПЕН

- Проверьте написание пути, доступность диска и права файловой системы.
- Убедитесь, что путь ведет к каталогу, а не к Markdown-файлу.
- Проверьте, не был ли vault перемещен после запуска Amber Desk.

### После перезапуска нет дела

- Проверьте подписи бэкенда. Данные `MEMORY` не переживают перезапуск.
- Убедитесь, что `OBSIDIAN_VAULT` настроен и подключен.
- Проверьте `Amber Desk/.state/cases-index.json` и `.state/cases/` в vault. Восстанавливайте их из резервной копии, не редактируя во время работы Amber Desk.

### Изменения из Obsidian не появились

- В редакторе VAULT нажмите **ПЕРЕЧИТАТЬ** для Markdown досье.
- Для хронологии, чеклиста, карты и связей обновите страницу браузера.
- При редактировании созданных заметок сохраняйте YAML frontmatter Amber Desk и ID дела.
- При ошибке разбора восстановите последнюю корректную версию файла из резервной копии.

### При сохранении досье показано ВНЕШНЕЕ ИЗМЕНЕНИЕ

После загрузки файл изменился. Нажмите **ПЕРЕЧИТАТЬ**, проверьте внешнюю версию, повторно внесите свою правку и сохраните.

### Подробная карта пустая

- Проверьте, что `MAP_TILE_DIR` - абсолютный путь и содержит файлы `{z}/{x}/{y}.<ext>`.
- Проверьте соответствие `MAP_TILE_EXT` и диапазона масштабов пакету.
- После изменения переменных перезапустите Amber Desk.
- Пакет не покажет названия или POI, которые не были отрисованы его создателем.

### Sherlock недоступен

- Запустите скрипт установки и прочитайте сообщение об ошибке.
- При использовании `SHERLOCK_PYTHON` укажите исполняемый файл Python, а не каталог окружения.
- Перезапустите Amber Desk.
- Открывайте приложение через `localhost` и оставьте `ALLOW_REMOTE_TOOL_RUNS=0`, если снятие ограничения не требуется.

### Sherlock показывает проблемы или ошибочные URL профилей

Используйте фильтр `ПРОБЛЕМЫ` для просмотра затронутых сервисов. Определение сервиса или его ответ могли измениться. Не импортируйте некорректные или сомнительные результаты. Обновляйте зафиксированную интеграцию только после проверки изменений upstream.

### Вложение отклоняется

- Максимум 20 файлов в одной карточке.
- Максимальный размер файла - 10 МиБ.
